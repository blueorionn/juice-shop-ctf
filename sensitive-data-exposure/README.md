# Sensitive Data Exposure

A sensitive data exposure vulnerability is a cybersecurity weakness that leads to the accidental or unauthorized disclosure of confidential information, such as personally identifiable information (PII), financial records, or credentials. Common causes include a lack of data encryption, weak access controls, insecure APIs, misconfigured cloud storage, and improper data disposal.
