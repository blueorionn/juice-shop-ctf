# Admin Section

## Objective

Access the administration section of the store.

## Solution

To access the **administration** section of the OWASP Juice Shop, you first need to log in as `administrator`.

The credentials for admin account is:

```text
email: admin@juice-sh.op
password: admin123
```

**You can find more about this in _[Broken Authentication Lab](../07_Broken-Authentication/01_Password-Strength.md)_**

Then search for keywords like `admin` or `administration`. After you find the object for the routing path, visit the URL (`/#/administration`).
